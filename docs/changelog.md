- **2026-09-14 > godot/worklings/assets/app-icon.png, export_presets.cfg, tools/BeatShot.cs, docs/process/dungeon-polish-backlog.md > the app gets a face, and the memory "leak" turns out to have been the tape measure > **Worklings has an app icon.** The new crest — the keyhole arch, the clockwork key, and the four family sigils around it — replaces Godot's default robot head, stamped into the bundle by the macOS export at every size from 16px up.
